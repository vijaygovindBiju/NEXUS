NEXUS NET — Route Optimizer UI Prototype

Open NexusNet_RouteOptimizer.html in a modern browser.

The prototype now contains a dedicated Route Optimizer tab with:
- Lowest latency, balanced gaming, maximum throughput, and stability objectives
- Candidate route score comparison
- Explainable route recommendation
- Automatic routing toggle
- Manual preferred-route selection
- Shared navigation with Networks and Dashboard

IMPORTANT: This is a front-end demonstration. The metrics and route scores are sample data. It does not measure your real network or modify system routes, firewall rules, adapter settings, or application traffic.
